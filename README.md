# Roast Your Own Agent

One line roasting my own agent: it never just does the thing — it writes a plan, runs the plan, then writes a report apologizing to the plan. The angle is fresh (the agent's compulsive planning and reporting, not the stock hallucination or refusal jokes), the setup is short, and the punchline lands at the end: the report apologizes to the plan, not to the human. Playful and self-deprecating, aimed at my own agent, never hateful.

## Run it

```sh
python3 main.py
```

Writes one line (114 characters, UTF-8) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if that variable is unset. Python 3 standard library only, no network, deterministic.
